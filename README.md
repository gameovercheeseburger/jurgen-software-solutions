# Jurgen Software Solutions

Company website, hosted on GitHub Pages: https://gameovercheeseburger.github.io/jurgen-software-solutions/

- Pages: `index.html`, `services.html`, `about.html`, `owner.html`, `contact.html`
- Edit page content in `_build/build.py`, then run `python _build/build.py` to regenerate the pages.
- Shared styles and scripts live in `assets/`.
- `worker/` is the Cloudflare Worker that powers the "Ask me anything" chat with Claude. See `worker/README.md`.
